# InSync

<p align="center">
  <img src="logo.png" alt="InSync logo" width="420">
</p>

InSync is a Chrome extension (Manifest V3) that scans the LinkedIn profile you're
currently viewing and reports what it finds — name, headline and verification badge —
straight from the page DOM, no LinkedIn API involved.

It pairs with a small native messaging host (`host.js`, run through `host.cmd`) that can
install and manage local companion tools on demand, streaming progress back into the
popup as it works.

## Features

- **One-click scan** — analyzes the active `linkedin.com/in/*` tab and extracts the
  profile name, title/description and verified-badge status.
- **Live progress feedback** — the popup shows a terminal-style log plus a progress bar
  while the page is scrolled and parsed.
- **Native host bridge** — talks to a local Node.js host over Chrome's native messaging
  protocol to install/update companion tools, downloading and unzipping them as needed.
- **Auto-enable on LinkedIn** — the toolbar icon is disabled everywhere except on
  LinkedIn profile pages.

The popup mimics a small terminal window: a title bar, a **SCAN** button, an output
console, a status line, and a progress bar that only appears while a scan is running.

> **Beta:** the extension is still under active development — expect rough edges.

## How it works

```
popup.js  --chrome.runtime.connect-->  background.js  --connectNative-->  host.cmd → host.js
   |                                        |                                  |
   | executeScript on the active tab        | routes "install" messages        | downloads/unzips
   | (scrolls + reads the profile DOM)       | between popup and native host    | companion tools
```

1. **`background.js`** is the service worker. It enables the toolbar icon only on
   `https://www.linkedin.com/*` pages, and relays messages between the popup and the
   native host over a long-lived port.
2. **`popup.js`** drives the popup UI. Clicking **Scan** injects a script into the
   active tab that auto-scrolls the profile (to force lazy-loaded content in), then
   reads the name, headline and verified badge from the page, reporting progress back
   to the popup as it goes.
3. **`host.js`** (launched via `host.cmd`, registered as the native messaging host
   `com.insync.linkedin` in `com.insync.linkedin.json`) receives `install` commands from
   the extension, downloads/unzips any missing companion tools, and streams status
   messages back to the popup. `host.cmd` also bootstraps Node.js itself (via `nvm` or a
   portable download) if it isn't already available on the machine.

## Installation

1. **Build the extension bundle**
   ```bash
   npm install
   npm run build
   ```
   This uglifies `background.js`, `popup.js`, `host.js` and `update-version.js` into
   `dist/`, which is what `manifest.json` and `popup.html` actually load.

2. **Load the unpacked extension in Chrome**
   - Go to `chrome://extensions`, enable **Developer mode**.
   - Click **Load unpacked** and select the `C:\InSync` folder.
   - Note the extension ID Chrome assigns it.

3. **Register the native messaging host**
   - `com.insync.linkedin.json` points to `host.cmd` and whitelists an
     `allowed_origins` extension ID. If your loaded extension gets a different ID,
     update that file to match.
   - Register the manifest in the registry under
     `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.insync.linkedin`, pointing to
     the full path of `com.insync.linkedin.json`.

4. **Use it**
   - Open any `https://www.linkedin.com/in/...` profile.
   - Click the InSync icon, then **Scan**. Results appear in the terminal panel.

## Project layout

| Path | Purpose |
| --- | --- |
| `manifest.json` | Chrome extension manifest (MV3). |
| `background.js` | Service worker: icon state + popup ↔ native host relay. |
| `popup.html` / `popup.css` / `popup.js` | Extension popup UI and scan logic. |
| `host.js` / `host.cmd` | Native messaging host: tool installation over stdio. |
| `com.insync.linkedin.json` | Native messaging host manifest for Chrome. |
| `update-version.js` | Bumps the version shown in `popup.html` during a release. |
| `dist/` | Build output (uglified via `terser`), generated by `npm run build`. |

## Scripts

- `npm run build` — clean `dist/` and uglify all top-level `.js` files into it.
- `npm run clean` — remove `dist/`.
- `npm run changelog` — regenerate `CHANGELOG.md` via `auto-changelog`.
- `npm run release -- [patch|minor|major|x.y.z]` — bump the version, regenerate the
  changelog, tag and push a release.
